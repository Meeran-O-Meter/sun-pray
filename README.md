# sun-pray
SunPray is a muslim website to calculate your prayer times for the day using your location, chosen calculation method, and school. 

I used the Al Adhan API for the prayer times with the geolocator API for the location. This was a super fun project since I learned a lot of JS, and CSS levelled up to Level 2. 
I also made sure to code a a mobile version along with designing it. I also implemented a real time clock because why not! I might as well display the time for a time-based website.

As my first shipped project as a 15 year old, this is probably going to hold a special place in my heart.  Have a wonderful day! Don't let the code bugs bite.
